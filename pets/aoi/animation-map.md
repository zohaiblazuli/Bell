# Aoi animation map

| Codex state | Aoi animation |
| --- | --- |
| `idle` | Idle — standing, breathing, and blinking |
| `running-right` | Directional movement to the right |
| `running-left` | Directional movement to the left |
| `waving` | Wave — greeting the user |
| `jumping` | Playful — wink, tongue out, and peace sign |
| `failed` | Error — confused head scratch and exclamation mark |
| `waiting` | Sleep — head on arms, closed eyes, and floating Zs |
| `running` | Working — glasses on, book open, and reading |
| `review` | Tickle — startled flinch and laughter |
